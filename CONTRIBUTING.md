# Contributing to Informed

## Setup (5 minutes)

### Prerequisites
- Node.js 18+
- npm or yarn
- GitHub account

### Local Setup
```bash
git clone https://github.com/[YOUR_USERNAME]/informed-app.git
cd informed-app

# Frontend
cd frontend
npm install
npm run dev  # Runs on localhost:3000

# Backend (in new terminal)
cd backend
npm install
npm run dev  # Runs on localhost:5000
